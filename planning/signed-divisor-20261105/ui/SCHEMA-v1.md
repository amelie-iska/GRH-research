Native gzip plus compressed/expanded SHA256; explicit unsupported/error state. Five steps: columns -> ideal incidence -> row raw masks/Fd -> mu(d)ZXY -> global. Shared row/column/divisor cursors, exact-ID/range controls, ten-row paged searchable tables. All states remain addressable; no thousands-option menus.
