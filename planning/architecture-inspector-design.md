# Architecture inspector implementation — 2026-11-03

Execute P1 against the existing immutable 22-case manifest, without training,
new dependencies or changing checkpoint/source pins. The interface is original
local Canvas/SVG/HTML code. It follows the existing project style and server.

One canonical in-book inspector links to its standalone page. It combines a
rotatable perspective DAG of actual trace tensors, step/play controls, literal
shape/axis/coordinate inspection, paged numeric heatmaps, quantum gate diagrams,
photonic covariance marginals, tropical witnesses and exact Harper certificate
records. All six trained families and six fixed-weight reference variants must
work. A separately computed finite forward clock/shift carrier is labelled as
such. Unsupported GPU/hardware and optional unimplemented upstream probes stay
explicitly labelled; they are not trained architectures.

Acceptance: hash-verified loading; finite/shape/DAG validation; exact tensor
indexing and masks including empty tropical blocks; phase and bit-order
conventions; reference/certificate status; responsive and keyboard controls;
browser coverage across all cases; screenshot inspection; independent review;
unique book embedding and valid staged PDF/HTML promotion.

Ruling: use the existing headless Chromium/CDP checks rather than install a new
browser runner — this preserves the project's dependency and environment pins.
Ruling: the 3D scene represents a computation graph and tensor cardinalities,
not literal spacetime, hardware geometry or a faithful infinite-order action.
Ruling: fixed-weight examples are replayed, not edited into purported trained
checkpoints; the finite clock carrier alone has live mathematical parameters.

Tests first cover data validation/indexing, exact tropical tie sets and invalid
blocks, finite carrier normalization/Weyl conventions, then browser data flow,
case switching, playback, orbit/zoom, slices, circuits, covariance and responsive
layout. The existing arithmetic low-gcd and positive-determinant lane remains
open; this implementation supplies no new GRH theorem.
