## Acceptance and scope

A JavaScript arithmetic check is a theorem-contract instance, not a Lean
kernel execution in the browser. The return path must emit fixed-template
Lean code that has been tested with the pinned compiler. Hashes identify
the source and type provenance; they do not authenticate arbitrary clients.

Floating logarithmic slider values are not silently promoted to exact
rationals. An exact Hodge input will expose the zero/coercivity boundary.
Finite-field group examples retain their exact finite interpretation.

Gauge refinement will use a newly declared physical family and spacing,
rather than silently assigning spacing to the existing single plaquette.
Fluid diagnostics will separate spatial truncation, time stepping,
roundoff heuristics and model discrepancy. Numerical convergence rates
do not become certified interval bounds.

The probability development will use real measures and integrable moment
hypotheses for a full finite scan, allowing correlated filters. The
Gaussian moment identity and ideal random sampling remain explicit model
obligations. A fixed pseudorandom calibration array is not itself a proof
of a probability law or a conditional false-positive rate.

Existing valid research and completed checks are preserved. Unrelated
upstream dependency failures, inaccessible papers and physical experimental
milestones are not relabeled complete. Credential material remains excluded.
