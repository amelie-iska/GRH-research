What transfers to the surface-order project
For m=2g+1, the clean dessin on y²=xᵐ−1, β=xᵐ has σ=(0 … m−1)(m … 2m−1), α(h)=h+m mod 2m, permitted successor τ=σ⁻¹, and forbidden successor φ=ατ. The corpus follows permitted arrows ahaτh… in the infinite polynomial algebra Ag=kQ/(ahaφh). Products here use travel order: ab traverses a first, then b; left-operator matrix products reverse this order. Vocabulary tokens name finite subpaths; decoding recovers the same arrow sequence, endpoints and length.


The genus-two/four examples restrict candidate tokens to two or three arrows, so their lower bounds concern that candidate set. They compress a finite path corpus and preserve the algebra's relations. The completed order has rank 2m² over k[[u]]; this is unrelated to the number of tokens. Idempotents, arbitrary formal sums, path multiplication and module maps require their own representation. TokenGT's node/edge feature tokens have a different meaning; replacing them would require explicit incidence metadata, model changes and new evaluation.
