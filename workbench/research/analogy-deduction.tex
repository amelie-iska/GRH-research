\section{Analogical transfer is a proposal; deduction is a checked consequence}
\label{sec:wb-analogy}

The inspected Mora-3 analogy head builds condition-only queries and complete-forest memory keys, with a train-only index, group identifiers and a frozen encoder specification. Its own configuration does not claim that a close latent key is a verified directed semantic mapping. This extension retains that distinction. Retrieval proposes a source construction; a typed graph witness checks its mapping; deduction accepts a consequence only when its premises and inference rule are supplied.

Let source and target transition systems be $f:X\to X$ and $g:Y\to Y$, and let $A:X\to Y$ be a proposed analogy. Suppose, on a declared operating region, $\|g(Ax)-A(fx)\|\le\delta$ and $g$ is $L$-Lipschitz. For $x_{t+1}=f(x_t)$ and $y_{t+1}=g(y_t)$, insertion of $g(Ax_t)$ gives
\[
 \|y_{t+1}-Ax_{t+1}\|\le L\|y_t-Ax_t\|+\delta.
\]
Induction yields the same finite-horizon geometric error sum as the earlier dynamical bound. This is a conditional transfer result: a nearest-neighbor score does not establish the commuting error premise. If a source edge maps to several target steps, replace $g$ by the explicitly specified composite along that target path and charge its accumulated error and cost.

The executable reference checks injective boundary-node typing, complete source-edge coverage, oriented target paths and an explicit allowed relation-word table. Reversing a path, omitting a branch or inventing a relation fails. These are syntactic certificates, not proofs that two measured physical processes obey the same equations. The deduction checker uses finite ground rules with known premises; adding a conclusion by similarity alone is rejected.

The real-data experiment uses embeddings from the actually trained small native encoder to retrieve only training-span windows. The input and memory windows share a declared directed lag-chain semantics; their targets are not included in query features. A validation-selected mixture compares retrieved conditional frequencies with the neural distribution. This is an implemented predictive analogy adapter, not the full native complete-forest head and not a discovered physical equivalence. Bank storage is charged in the two-part code length. An improvement that disappears after storage cost is included is still useful to report, but it is not a compression victory under that accounting.

For cross-system transfer, dimensions and units must first be aligned by a declared transformation fitted without target-test access. Validation must compare the transferred rule with target-only, no-retrieval and unconstrained-nearest baselines. Source and target grouping must exclude shared trajectories, equivalent simulations and post-outcome annotations. Unknown pairs are not automatically negative examples. A successful finite mapping can be retained as a reusable proof or program fragment only at the level actually checked.
