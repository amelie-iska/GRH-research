# Expanded language and graph-computation research

The source extends the existing monograph's `learning-languages.tex` treatment.
It separates bounded approximation, uniform computability, resource complexity,
learning and operational semantic competence. Initial authored sections include
corrected graph approximation contracts, finite-group symmetrization, decoding
margins, an explicit growing-graph Turing simulation, the language hierarchy,
semiring parsing, exact Boolean-circuit interpretation and resistor-network
residual certificates.

The source audit records an important metric distinction: the cited Yun theorem
uses Lp approximation, not a supremum error. The theorem transfer must also
specify the tokenizer, distribution, relabeling action and output decoder.
Architecture names and added branches alone do not discharge these hypotheses.

This checkpoint is written research source, not a newly trained model or a
recompiled historical release. The next source checkpoint completes the
ConvexTok/GFlowNet/quantum/dynamical/categorical discussion and references before
standalone compilation and monograph integration.
