# Linked circuit / cover / sky visual contract

One page has three linked sections, not a decorative dashboard. Resource evidence
and actual emitted reversible gates appear first; covering and channel hierarchy
second; observed sky and full-search control third. SVG owns the modest gate,
finite graph and training/kernel curves. Canvas owns the 3072-pixel scientific sky
map. Numeric tables provide exact values and keyboard alternatives.

A single version-pinned JSON manifest binds all data to SHA-256 hashes. The
browser runs emitted ECC gates on a chosen basis input, checks clean registers,
compares exact point arithmetic, and displays a paginated slice of the gate
stream. The curve and endomorphism choices update counts and circuit together.

Cover selection shows lifted vertices, arrow directions, sheet identities and
local-bijection checks. Quantum hierarchy selection uses genuinely trained gate
parameters. A four-angle test state is evolved by the existing four-qubit dense
kernel; learned effective-Hamiltonian/truncation curves remain explicitly the
precomputed Gibbs-state experiment. Independent-feature width is plotted as its
own experiment, not confused with cover degree or qubit count.

Sky product/method/center/amplitude state is URL-backed. Observed values are
separate from a labeled synthetic profile injection. Every changed input reruns
all fixed templates with the frozen classifier and the unchanged calibration.
The displayed value is a phase-surrogate rank, not a physical CCC probability.
The exploratory common-null and frequency-residual results remain labeled as
post-inspection followups and are not folded into the original family bound.

All views have focusable controls, readable labels, mobile layouts and export.
No action depends only on hover. Real data, model-derived values and simulations
have distinct text labels. Test exact JS/Python score and circuit parity before
browser interaction checks; test stale state, data hash failures, reset, keyboard,
mobile overflow, source identity and export. No authentication is needed to read
public assets, and no remote kernel server is implied by static hosting.
