# Exact research workbench

This independently versioned extension preserves the existing historical atlas
release while adding executable connections. Initial checkpoint: exact Python
and JavaScript contracts for positive heat stencils, weighted gain contraction,
Monte Carlo ranks, family-wise risk budgets, and skew-symmetric quiver/seed
mutation. `contracts.py` also checks quadratic monomial gentle conditions,
including finite dimensionality through the allowed-path graph.

Run `python3 workbench/tests/test_contracts.py` (Python standard library and Node).
The initial nine test methods cover 375 matrix/seed/tropical involution cases,
175 Python/JavaScript certificate comparisons, the labeled A2 pentagon,
adversarial parsers and witnesses, and the exact binary64 handoff.

Passing arithmetic is not yet Lean kernel verification, observational evidence,
a continuum limit, or a derived-equivalence certificate. Every exported object
contains its narrow scope. Later checkpoints add the live interface, proof
replay, numerical diagnostics, research synthesis and dataset publication.
