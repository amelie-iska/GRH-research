# Tensor, grammar and language source review

Primary-source passages supporting the two authored tensor/grammar and language chapters. This is a selected-passage review, not a declaration that all linked literature was fully audited.

The full primary PDFs were retrieved and hashed for inspection, but reading coverage is explicitly limited below. The third-party PDF cache is excluded from publication. No model was retrained from the linguistic papers.
