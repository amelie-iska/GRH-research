# GRH research

An audit and formal-verification project investigating surface-order and Hilbert–Pólya approaches to GRH.

**Status: research in progress; no complete proof of GRH has been established.** The supplied proof claims contain explicit false intermediate statements. See [planning](planning/IMPLEMENTATION_PLAN.md), the [design](planning/DESIGN.md), and the forthcoming claim-level audit.

Source clones remain unchanged and will all be pinned as Git submodules once cloning completes. The new papers will have a concise and an extended edition, with exact proof status and reproducible checks. A successful Lean build verifies only the theorems actually present, not the outstanding GRH argument.

No MCP server was enabled. No source datasets, environments, caches, or source repository history were removed or rewritten.
