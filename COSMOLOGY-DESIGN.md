# Cosmology companion: implementation contract

## Analytical job and reading path

The page explains spatial template detection and the distribution of a maximum
over a declared search. The primary evidence is the actual recorded synthetic
null result: selected local tail 0.00329237, global rank p 0.46215820. The first
interactive module lets a reader add a signal and see the same calculation.
The second module separates physical transfer, encoding hypotheses, observed
records and inference. Primary papers and the manuscript supply the wider
cosmological context.

## Rendering ownership and data contract

Use native SVG and HTML, without D3, Canvas, WebGL or external JavaScript. At
only 96 sampled positions and 30 histogram bins, SVG is simpler and more
inspectable than a raster or GPU renderer. There are three substantial vector
views: sampled sphere/map, calibration histogram, and a typed schematic. The
sphere is an orthographic projection of actual unit-vector coordinates; it is
not a surface interpolation or a CMB map. A longitude/latitude view shows all
samples. The schematic carries no measured data and is explicitly labeled.

`data/cosmology-synthetic.json` is generated by
`extension/review/cosmology/synthetic_search.py --site-output ...` and contains
the exact fixed Python fixture: 96 unit directions, one base noise sky,
288 normalized injection vectors, 288 normalized filter vectors, sorted maxima
from 4,095 independent null skies, labels, benchmark results and source hash.
JavaScript computes `sky = base + snr * injection`, all 288 dot products,
their maximum, and the exact rank count in the stored calibration sample.
The small normal-tail approximation is checked against the Python `erfc`
reference. No catalog, covariance, seed or normalization control is exposed.
Global p remains tied to the same declared search and null; each live display
is a hypothetical synthetic record, not new observational evidence.

## Interaction, state and mobile

Controls select an injection center, one of three declared widths and a
matched-SNR amplitude. Presets restore the four recorded experiments. Map
points offer a pointer shortcut to the same center selector; the select is the
complete keyboard alternative. View rotation uses labeled sliders, without
drag or wheel interception, so touch scrolling and browser zoom remain native.
Projection, center, width, amplitude and rotation are encoded as bounded URL
parameters; the permalink preserves them. Invalid inputs use safe defaults.

On narrow screens the sky comes before the numerical comparison and histogram.
Each SVG is redrawn using its container width; labels remain readable rather
than shrinking a desktop diagram. Controls have minimum 44-pixel heights.
There is no continuous animation or motion dependency. Only this local fixture
is fetched; the static recorded table and source links remain usable if the
fetch fails or JavaScript is unavailable.

## Encodings and access

Teal/neutral/ochre encode negative/zero/positive sample values with a visible
numeric scale. Equal-sized points are samples, not population or importance.
A black diamond locates the injected center; an ochre square locates the
winning template center. Their identities and exact values also appear in
HTML. Histogram bars show calibration counts; a vertical line marks the live
maximum. Essential values are always visible without hover. Text descriptions,
SVG titles and a 96-row inspectable sample table support nonvisual reading.
The schematic uses dashed hypotheses and solid mathematical/data operations,
with text naming each type. It does not assert a verified cross-aeon channel.

## Verification boundary

Node checks load the same JSON and compare all four live recomputations with
the authentic Python benchmark; check all filter/injection self-pairings,
projection norms, rank-p boundaries/ties, normal tails and URL validation.
They also check the 96-point/288-template/4,095-calibration dimensions and
finite values. The root agent owns actual browser QA at desktop and mobile
sizes, including failed-load behavior and the synthetic/no-observations labels.
These checks do not reproduce Planck analyses or validate CCC dynamics.
